## The idea  
The periodic table arranges elements by increasing atomic number, the count of protons in the nucleus. Elements in the same vertical column (group) have the same number of valence electrons, so they behave similarly in chemical reactions.

## Why your answer happened  
Many students think the table is ordered by atomic mass, so they pick the wrong element when asked about a specific atomic number. This feels reasonable because heavier elements often appear lower in the table, but the real rule is the proton count.

## Analogy  
Think of the table like a sports league draft.  
- **Atomic number** is the draft pick number; each player (element) gets a unique spot.  
- **Groups** are like positions (e.g., forwards, defenders). All forwards have similar responsibilities (valence electrons).  
- **Periods** are like the seasons; each season adds a new set of players (new energy levels).

So, just as a team knows that all forwards share similar skills, the table tells us that all elements in a group share valence‑electron patterns.

## Worked example  
Find the element with atomic number 12.  
1. Start at the top left: H (1).  
2. Move right across the first period: He (2).  
3. Continue to the second period: Li (3), Be (4), B (5), C (6), N (7), O (8), F (9), Ne (10).  
4. Now the third period: Na (11), **Mg (12)**.  
So the element is magnesium, symbol **Mg**.
