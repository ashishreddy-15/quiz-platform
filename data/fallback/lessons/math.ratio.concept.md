## The idea
A ratio tells us how many times one quantity contains another.  
If we write the ratio of apples to oranges as $3:4$, it means that for every 3 apples there are 4 oranges.  
Two ratios are equivalent when both numbers are multiplied (or divided) by the same factor. For example, $3:4$ and $6:8$ are equivalent because each term of $3:4$ was multiplied by 2.

## Why your answer happened
You wrote $3:4 = 3:8$, thinking the second number should be doubled because the first number stayed the same. This is a common mix‑up: we often change only one part of the ratio, but the definition requires *both* parts to be scaled together. Keeping one term fixed while changing the other does not preserve the same relationship.

## Analogy
Think of a basketball team’s lineup.  
- The **ratio** is like the **coach’s instruction “play 3 guards and 4 forwards.”**  
- Scaling the ratio is like the coach saying “play **6** guards and **8** forwards” – every position count is doubled, so the team’s balance stays the same.  
If the coach changed only the number of forwards to 8 while keeping 3 guards, the team would no longer follow the original balance.

## Worked example
Suppose the ratio of wins to losses for a player is $5:2$.

1. **Find an equivalent ratio by multiplying both terms by 3.**  
   $$5 \times 3 = 15,\qquad 2 \times 3 = 6$$  
   So $5:2 = 15:6$.

2. **Check equivalence by dividing.**  
   $$\frac{15}{6} = \frac{5}{2} = 2.5$$  
   Both fractions give the same value, confirming the ratios are equivalent.

3. **Create another equivalent ratio by dividing both terms by 5** (if possible).  
   $$\frac{5}{5}=1,\qquad \frac{2}{5}=0.4$$  
   The ratio $5:2$ is also equivalent to $1:0.4$, though we usually keep whole numbers.

## Try this
A soccer coach wants a ratio of defenders to midfielders of $4:5$. Write an equivalent ratio where the total number of players is 27.

<details><summary>Answer</summary>
Multiply both terms by the same factor $k$ so that $4k+5k=27$.  
$9k = 27 \;\Rightarrow\; k = 3$.  
Thus the equivalent ratio is $4\cdot3 : 5\cdot3 = 12:15$.</details>
