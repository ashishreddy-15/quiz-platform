## The idea
An equivalent fraction is a different looking fraction that represents the same part of a whole.  
If you multiply **both** the top number (numerator) and the bottom number (denominator) by the same non‑zero whole number, the size of the fraction does not change.  
Doing the same with addition (adding the same amount to numerator and denominator) **does** change the size, so the fractions are not equivalent.

## Why your answer happened
You tried to add the same number to the numerator and denominator, thinking it would keep the fraction the same. That feels reasonable because you were treating “adding the same amount” like “multiplying by the same amount.” The trick is that multiplication stretches both parts proportionally, while addition does not keep the ratio unchanged.

## Analogy
Think of a basketball team’s win‑loss record.  
- The **wins** are like the numerator.  
- The **total games played** are like the denominator.  

If the team plays *twice* as many games and wins *twice* as many, the win percentage stays the same: $8/12$ becomes $16/24$.  
But if the team wins *2* more games **and** plays *2* more games, the percentage changes: $8/12$ becomes $10/14$, which is a different win rate.

## Worked example
Find an equivalent fraction for $\displaystyle \frac{3}{5}$ by multiplying numerator and denominator by $4$.

1. Multiply the numerator: $3 \times 4 = 12$  
2. Multiply the denominator: $5 \times 4 = 20$  

So,
$$\frac{3}{5} = \frac{12}{20}$$

Check the equality by comparing the decimal values:
$$\frac{3}{5}=0.6,\qquad \frac{12}{20}=0.6$$  
Both give the same value, confirming they are equivalent.

## Try this
What fraction is equivalent to $\displaystyle \frac{7}{9}$ if you multiply numerator and denominator by $3$?

<details><summary>Answer</summary>
$$\frac{7}{9} = \frac{7\times 3}{9\times 3} = \frac{21}{27}$$
</details>
