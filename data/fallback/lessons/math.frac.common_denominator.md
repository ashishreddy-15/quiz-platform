## The idea
When we add or compare fractions, the denominators (the bottom numbers) must be the same. We do this by finding a *common denominator*—a number that both original denominators can divide into. Then we rewrite each fraction as an equivalent one whose denominator is that common number. The value of the fraction does not change; only its appearance does.

## Why your answer happened
You probably tried to add the numerators while keeping the original denominators, like $\frac{1}{4} + \frac{2}{5} = \frac{3}{9}$. That feels natural because you’re “adding” the top parts, but the bottom parts still represent different sized pieces, so the result isn’t correct. The mistake comes from mixing up “adding numerators” with “finding a common denominator.”

## Analogy
Think of a basketball game where each team scores points in different ways: one team gets 2‑point shots, the other gets 3‑point shots. To compare total points, you convert everything to the same “point unit.”  
- The *denominator* is like the type of shot (2‑point or 3‑point).  
- The *common denominator* is a new scoring system where every shot is counted as 6 points (the least common multiple of 2 and 3).  
- Each original score is rewritten in this 6‑point system so you can add them fairly.

## Worked example
Add $\displaystyle \frac{1}{4}$ and $\displaystyle \frac{2}{5}$.

1. Find the least common multiple (LCM) of 4 and 5.  
   $$\text{LCM}(4,5)=20$$
2. Rewrite each fraction with denominator 20.  

   For $\frac{1}{4}$: multiply numerator and denominator by $5$ (because $4\times5=20$).  
   $$\frac{1}{4} = \frac{1\times5}{4\times5} = \frac{5}{20}$$  

   For $\frac{2}{5}$: multiply numerator and denominator by $4$ (because $5\times4=20$).  
   $$\frac{2}{5} = \frac{2\times4}{5\times4} = \frac{8}{20}$$
3. Add the new fractions.  
   $$\frac{5}{20} + \frac{8}{20} = \frac{5+8}{20} = \frac{13}{20}$$
So, $\displaystyle \frac{1}{4} + \frac{2}{5} = \frac{13}{20}$.

## Try this
What is $\displaystyle \frac{3}{6} + \frac{2}{9}$ expressed with a common denominator?

<details><summary>Answer</summary>
The LCM of 6 and 9 is 18.  
$\frac{3}{6} = \frac{3\times3}{6\times3} = \frac{9}{18}$  
$\frac{2}{9} = \frac{2\times2}{9\times2} = \frac{4}{18}$  
Add: $\frac{9}{18} + \frac{4}{18} = \frac{13}{18}$.
</details>
